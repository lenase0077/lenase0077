## 🧠 About Me

I'm a programmer who enjoys understanding **how things work under the hood**.

My main languages are **C++ and Python**, but I'm comfortable exploring different ecosystems and programming paradigms. I've worked with **Java, Rust, Go, .NET, JavaScript, and SQL**, alongside technologies for web development, data analysis, machine learning, and game development.

I'm less interested in collecting frameworks and more interested in understanding the **fundamentals behind them**.

I like projects that force me to learn something new — whether that's a different language, a new architecture, an unfamiliar codebase, or a problem I've never encountered before.

Currently studying **University Technician in Programming at UTN**, while building projects, experimenting with new technologies, and occasionally going way too deep into things that probably didn't need that much investigation.

---

## 🐙 The Tech Octopus

I tend to collect technologies the same way an octopus collects tentacles.

Not because I want to know everything, but because **different tools teach different ways of thinking**.

```text
C++       → Systems, OOP, memory, performance
Python    → Automation, data, ML, scripting
Java      → OOP, application development
Rust      → Safety, systems programming, modern tooling
Go        → Backend, concurrency, simplicity
.NET      → Application & backend development
JavaScript → Web development
SQL       → Data & databases
```

The goal isn't to master every language.

The goal is to become good enough at programming that **the language becomes a tool rather than a limitation**.

## 🎮 Game Development & Modding

Outside of traditional software development, I'm also involved in **game development and modding**, particularly around **Minecraft and Hytale**.

Modding has been one of my favorite ways to learn because it involves dealing with unfamiliar APIs, existing codebases, game systems, debugging, optimization, and software that other people actually use.

It also has a habit of turning:

> *"I'll just make a small change."*

into:

> *"Why am I reading decompiled bytecode at 3 AM?"*

So naturally, I enjoy it.
